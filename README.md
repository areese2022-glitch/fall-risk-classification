#**fall-risk-classification**
Repository for classifying non-faller and faller patients based on the Long Term Movement Monitoring Database (LTMM).

The source of the data can be found at [PhysioNet](https://physionet.org/content/ltmm/1.0.0/#files-panel)

*Note: The Colab Notebook for this project was created before the creation of the repository, so the Background, Data, Auditing, and References sections were created prior.
